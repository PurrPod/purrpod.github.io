先把 PurrCat 装起来Install PurrCat first

一条命令装好，再启动桌面端；接口默认监听 http://127.0.0.1:8000。 Install with one command, then launch the desktop app. The API listens on http://127.0.0.1:8000 by default.

Install via
$ curl -fsSL https://raw.githubusercontent.com/PurrPod/purrcat/main/install.sh | bash
> irm https://raw.githubusercontent.com/PurrPod/purrcat/main/install.ps1 | iex
$ git clone https://github.com/PurrPod/purrcat ~/purrcat

01 启动桌面端Launch the desktop app

$ purrcat desktop start

默认走 http://127.0.0.1:8000，端口被占用时会自动顺延；需要固定端口就用 PURRCAT_API_PORT 指定。 The API listens on http://127.0.0.1:8000 and quietly moves to the next free port when that one is taken. Pin it with PURRCAT_API_PORT if you need to.

什么是 PurrCat？What is PurrCat?

一个基于信息熵不可逆性理念设计的 Agent 底座。 An agent foundation designed around the irreversibility of information entropy.

信息一旦丢失，就无法保证被完整还原。就像一张被打上马赛克的图片，即使最强大的模型，也只能根据剩余信息推测原貌，而无法保证还原出真实的原图。 Once information is lost, nothing guarantees it can be fully restored. Like a picture with a mosaic over it: even the strongest model can only guess at what was there from what remains — it cannot promise the original back.

人与 Agent 的沟通也是如此。你表达的需求、任务中的背景、执行过程中的发现，都可能在传递中遗漏、压缩或失真。模型能力越强，并不意味着它就能自动知道你真正想要什么。 The same goes for how you talk to an agent: the needs you express, the context behind a task, the discoveries made while running it — any of them can be dropped, compressed, or distorted on the way. A stronger model does not automatically know what you actually want.

我们尊重信息熵不可逆这一事实。因此，PurrCat 不仅致力于提升 Agent 的任务交付能力，更致力于打造你与 Agent 之间更方便、更高效的信息信道。 We take the irreversibility of information entropy as a given. So PurrCat works not only to raise the agent's task delivery, but to build a more convenient and more efficient information channel between you and your agent.

让你的意图更容易表达，让必要的信息更准确地流动，让 Agent 更贴近你真正想要的结果。 Make your intent easier to express, let the necessary information flow more accurately, and bring the agent closer to the result you actually want.

Build an Agent That Works Your Way. Build an Agent That Works Your Way.

为什么选择 PurrCat？Why PurrCat?

我们相信，好的 Agent 不应该只追求更强的模型，还应该拥有更好的信息流转方式。 We believe a good agent should not only chase a stronger model, but also carry a better way for information to flow.

模型会越来越强，工具会越来越多，Agent 能承担的任务也会越来越复杂。但有一件事不会因此自动消失：Agent 无法凭空获得你没有表达、系统也无法可靠推断的信息。 Models will keep getting stronger, tools will keep multiplying, and the tasks an agent can take on will keep getting more complex — but one thing will not disappear on its own: an agent cannot conjure information you never expressed and the system cannot reliably infer.

因此，我们希望 Agent 的进步，不只体现在模型能力上，也体现在人与 Agent 之间的信息如何表达、组织、传递和留存。 So we want the agent's progress to show up not only in model capability, but in how information between you and the agent is expressed, organised, passed on, and kept.

这就是 PurrCat 的设计出发点：提升任务交付能力，打造更好的信息信道，让 Agent 不只更强，也更懂得按照你的方式工作。 That is where PurrCat's design starts: raise task delivery and build a better information channel, so the agent is not only stronger — it also knows how to work your way.

0101

让沟通不再局限于文字Communication beyond text alone

有些需求，点一下比说十句话更清楚。通过可定制的 UI 插件、交互式界面和上下文补充机制，你可以直接向 Agent 表达意图，而不必每次都从头描述。 Some needs are clearer with one click than with ten sentences. With customisable UI plugins, interactive interfaces, and context-supplementing mechanisms, you can put intent straight in front of the agent instead of describing it from scratch each time.

更方便地表达，就是更高效地协作。 Expressing it easily is collaborating efficiently.

0202

让信息按照你的方式流动Information flows your way

每个人的工作方式都不一样，Agent 也不应该只有一种固定的工作方式。通过可编排的工作流、自定义 Agent Loop 和灵活的插件机制，你可以决定任务如何拆分、信息何时注入、工具何时调用，以及不同执行阶段如何协作。 Everyone works differently, so an agent should not be stuck with one fixed way of working. With composable workflows, a custom Agent Loop, and a flexible plugin system, you decide how a task is split, when information is injected, when tools are called, and how stages cooperate.

不是让你适应 Agent，而是让 Agent 适应你。 It is not you adapting to the agent, but the agent adapting to you.

0303

让重要的信息留得下来What matters stays

完成一次任务不应该意味着所有经验都随之消失。PurrCat 通过多层记忆系统，帮助 Agent 留存事件、提取相关知识，并在后续任务中找回需要的信息。 Finishing a task should not mean every bit of experience vanishes with it. Through a multi-layer memory system, PurrCat helps the agent keep events, extract relevant knowledge, and find what it needs again in later tasks.

让过去的工作，成为未来的上下文。 Let past work become future context.

0404

让一切成为插件Everything is a plugin

PurrCat 将信源、信道、信息流转方式以及外部工具等相关逻辑抽象成了六大类插件，Agent 能力边界由插件决定，蕴含无限可能。你也可以在此基础上轻松造出独属于自己的 Agent。 PurrCat abstracts the source, the channel, the way information flows, and external tools into six major plugin types. The agent's capability boundary is defined by its plugins, and the possibilities are endless — you can easily build an Agent of your own on that foundation.

一套插件机制，装下 Agent 所有的可能性。 One plugin mechanism, every possibility for the agent.

0505

让 Agent 的能力持续生长Capability that keeps growing

工具、技能和工作流不必永远由开发者手工编写。PurrCat 的进化工厂支持 Agent 构建新的扩展能力，并通过评估、迭代和记录来验证改进效果。 Tools, skills, and workflows do not have to be hand-written by developers forever. PurrCat's evolution factory lets the agent build new extensions, then validates the improvements through evaluation, iteration, and records.

不只使用能力，也让能力有机会被创造和改进。 Not just using capability — creating and improving it.

0606

让自主工作拥有明确的边界Autonomy with clear boundaries

Agent 可以持续工作，但自主不意味着不受约束。PurrCat 通过独立执行沙箱、受控的文件交互，以及 Heartbeat 与 Goal 机制，为 Agent 提供持续工作的环境与明确的运行边界。 An agent can keep working, but autonomy does not mean being unconstrained. With an isolated execution sandbox, controlled file interaction, and the Heartbeat and Goal mechanisms, PurrCat gives the agent a place to keep working and clear limits to work within.

让 Agent 更自主，也让你更安心。 More autonomy for the agent, more peace of mind for you.
