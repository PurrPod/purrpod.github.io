开发指南

框架按扩展深度提供五层机制：人格（SOUL.md）、Skill、Graph、自定义工具（MCP）、Sensor 与 AgentLoop（PARADIGM）。拆成了六张小卡片，按需取用。

01

Agent 人格（SOUL.md）

编辑 .purrcat/core/SOUL.md，修改 Agent 的性格、语气和价值观，或直接在前端界面修改——最轻量的一层扩展。

#SOUL#零代码
02

Skill 开发

遵循 Anthropic Skill 官方规范：一个目录 + 一份 SKILL.md 即成技能。也可以用 Trace2Skill 从一次经历中直接生成。

#Skill#Trace2Skill
03

Graph 开发

在前端 Editor 拖拽搭建思维链与工作流：多态节点矩阵、JSON 热插拔、状态机回滚，还有 KVCache 接线原则。

#DAG#Editor
04

自定义工具（MCP）

八大原生工具之外的扩展，走标准 MCP 协议：写个 Server、注册一段 JSON，启动时自动拉取 Schema 并热加载。

#MCP#热加载
05

Sensor 开发（ACP 方言）

独立子进程 + stdio JSON-RPC，PEP 723 内联依赖即装即用：完整接口表、最简实现与注册配置都在这页。

#Sensor#ACP
06

AgentLoop（PARADIGM）

用近自然语言的规则重写 Agent 主循环：五个 Hook、六种动作、退出关卡。附贡献开发原则。

#PARADIGM#Hook

只想换个性格 → 从 SOUL.md 开始；想教它新本事 → Skill；想编排复杂任务 → Graph；想接外部工具与感知 → MCP / Sensor；想彻底改写循环行为 → PARADIGM。
