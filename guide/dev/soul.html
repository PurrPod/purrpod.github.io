Agent 人格（SOUL.md）

开发指南 · 扩展层级 1 / 6——最轻量的一层：改一个文件，换一种性格。

修改 Agent 人格

编辑 .purrcat/core/SOUL.md，修改 Agent 的性格、语气和价值观，或直接在前端界面修改。

SOUL.md 是 Agent 的「性格底座」：语气、口头禅、价值观都写在这里。它会在构建系统提示词时被注入，奠定 Agent 的行为基调。
