PurrCat 生态

对 PurrCat 而言，除内核之外一切皆插件。插件规范零架构依赖——为 PurrCat 写的插件可以反哺整个 Agent 生态，其它项目的插件也能低成本搬进来。

官方仓库

- official repos -
github.com/PurrPod/purrcat

主仓库 · purrcat

框架本体：混合记忆、DAG 工作流、沙盒安全、传感器网关、自进化工厂。全部插件品类的样例实现也开源在这里，应用内插件市场可一键安装。

GitHub →
github.com/PurrPod/sensors

传感器仓库 · sensors

官方传感器集合：System（心跳轮询）、Feishu（WebSocket）、RSS 等。本地缺失的传感器脚本在启动时会自动从这里拉取，配置即安装。

GitHub →
github.com/PurrPod/mcps

MCP 工具集 · mcps

官方精选 MCP 服务器接入样例：粘贴一段标准 JSON 到 mcp_config.json 即可零代码接入，握手后工具树自动热更新。

GitHub →
github.com/PurrPod/skills

社区技能集 · skills

将包含 SKILL.md 的技能目录放入 ~/.purrcat/skills 即自动加载至检索树。好技能值得被所有人复用，欢迎提 PR 分享。

GitHub →
github.com/PurrPod/graphs

图谱广场 · graphs

把好用的 Harness 工作流导出为 JSON 分享给其他人，一键导入即用。好图谱值得流转起来，快来晒出你的编排。

从开发指南开始

五层扩展机制总有一层适合你：改人格、写 Skill、拖 Graph、接 MCP、造 Sensor。改配置就能重写 Agent。

#上手

提 Issue / 许愿

发现 bug、想许愿新功能、对架构有想法——都欢迎来开个帖子。涉及项目核心的更改会先在 issue 里讨论。

#反馈#讨论

1. 一个 PR 只解决一个问题；

2. 涉及核心的更改先开 issue 讨论；

3. 涉及宿主机文件操作必须校验路径映射；

4. 提交信息用英文；

5. 异常提示要人性化。
